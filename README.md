# Mentalplay – Testversion

Installierbare Web-App für sportbezogenes Mentaltraining. Testversion für einen kleinen Kreis.

- Läuft im Browser, auch offline, und lässt sich auf den Startbildschirm legen.
- Kein Konto, keine Datenübermittlung: Eingaben bleiben im Browser des Geräts.
- Trainingsreflexion für den Sport, keine Diagnose und keine Therapie. Ab 18 Jahren.
- Inhalte sind Entwürfe ohne fachliche Freigabe.

Bei akuter Gefahr: Notruf 144. Die Dargebotene Hand: 143.
